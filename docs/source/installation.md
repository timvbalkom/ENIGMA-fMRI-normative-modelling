# Installation

We’re using a new version of HALFpipe that deals with bugs essential for resting-state fMRI preprocessing. **Please do not use the standard “latest” HALFpipe version for this project.** You can find the correct HALFpipe version using the download links below.

::::{tab-set}

:::{tab-item} Apptainer/Singularity direct download
```bash
wget https://surfdrive.surf.nl/s/ikDotZQx7YHJLdm/download
```
:::

:::{tab-item} Docker/Podman
For now, Apptainer/Singularity is recommended. Let us know if you prefer/require Docker/Podman. Instructions will follow soon&trade;!
:::

::::

For more information on the installation of HALFpipe, please refer to [the HALFpipe installation documentation](https://fmri.science/halfpipe/installation.html).

You can find information on how to install Apptainer/Singularity here as well.

```{note}
Note that you'll also need a FreeSurfer license for this processing pipeline. Most ENIGMA-PD sites will have one; you can request one [here](https://surfer.nmr.mgh.harvard.edu/registration.html).
```

# Download prerequisite atlas and seed images

## Atlases
We will use two atlases for the resting-state functional connectivity matrices (download [here](https://surfdrive.surf.nl/s/Ew6zrpHifSAHYmm)): the HALFpipe standard Schaefer 400P17N + aseg atlas (`Schaefer2018Combined`) and the Schaefer 400P7N + Melbourne Subcortical Atlas S3 (`Schaefer400P7NMSAS3`). Store these in your working directory, in a folder named e.g., `atlases`.

## Seed regions
Additionally, we would like to use this opportunity to also compute seed-based connectivity of the substantia nigra and nucleus basalis of Meynert (download [here](https://surfdrive.surf.nl/s/MHPrGw22DJ22YrH)). Store these in your working directory, in a folder named e.g., `seed_regions`.
